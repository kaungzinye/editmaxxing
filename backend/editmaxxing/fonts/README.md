# TikTok Sans

The app and renderer use TikTok Sans. Caption and title renders use the static 36pt Bold build. The endpoint client uses 16pt Regular and 36pt Bold.

These unmodified files come from TikTok's [v4.000 release](https://github.com/tiktok/TikTokSans/releases/tag/v4.000). [OFL.txt](OFL.txt) contains the SIL Open Font License 1.1 and attribution. Bundle the license with copies of the fonts.
